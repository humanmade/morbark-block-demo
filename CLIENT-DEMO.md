# Try the Morbark block editor

[Open the interactive demo](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fhumanmade%2Fmorbark-block-demo%2F367146361bf67ed96a7f32ed4679a80adc9db4b6%2Fblueprint-v2.json)

Please allow the demo to finish loading. It opens the homepage in the WordPress visual editor.

- Use **+ → Patterns → Alamo Morbark Demo** to add any of the 18 reusable sections.
- Use **List View** to select and rearrange sections, or use a selected section’s drag handle.
- Edit headings, text, images and buttons directly in the canvas.
- Use **Save** and **View Page** to preview your changes.

Each person gets an independent WordPress instance in their browser. Edits are not shared with anyone else. This is a demonstration; enquiry forms do not send messages.

The package contains the public website demonstration and sample content. It does not include commercial briefs or meeting notes.
