# Morbark block editor demo

[**Open the interactive WordPress editor**](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fhumanmade%2Fmorbark-block-demo%2Fb6de418fb5b6c847da34e7c927fcc6cd48c19374%2Fblueprint-v5.json)

The demo opens the Morbark homepage in the visual block editor. Each visitor gets their own independent browser copy.

## Try it

1. Wait for WordPress to finish preparing.
2. Click **+ → Patterns → Alamo Morbark Demo** to insert any of the 18 section patterns.
3. Open **List View** to select and rearrange sections, or use the selected section’s drag handle and movement arrows.
4. Edit text, images and buttons, then click **Save** and **View Page**.

The homepage, product page, reusable section showcase, sample equipment, news and images are included. Enquiry forms are demonstrations and do not send messages. No commercial brief or call notes are included.

This is a browser sandbox, not a shared hosted WordPress installation. Changes are not automatically sent back to Human Made. Use Playground’s save/export controls if you wish to keep your experiments.

## Files

- `blueprint.json`: WordPress setup, demo theme and 18 reusable patterns.
- `demo-data.json`: sample content and website imagery.
- `CLIENT-DEMO.md`: instructions to share with reviewers.

## Design refinement

The refined version uses Poppins, light-weight headings, compact outlined buttons, wider image-and-text sections, full-width support-card photography, a three-panel still-image hero, and a homepage order closer to Morbark’s live site. The hero uses still frames captured from Morbark’s live homepage videos; some copy remains demonstration text. All homepage sections remain native editable WordPress blocks.
